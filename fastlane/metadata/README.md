# App Store metadata

Generated by the `vibe-aso` phase 2 pass. Pushed with:

```
fastlane deliver --skip-binary-upload --skip-screenshots --force
```

**Serbian is not an App Store metadata locale.** Apple's list has no `sr`;
the Serbia storefront defaults to English (U.K.) with Croatian as its
additional language. So the listing set is `en-US`, `en-GB` (what Serbia
actually shows) and `hr` (reaches Serbia, Croatia, Bosnia and Montenegro).
The app's own in-app `sr` strings are unaffected — iOS app localization and
App Store listing localization are different lists.

Name, subtitle, keywords and description only change with a new app version.
`promotional_text` is the one field editable in place on a live listing.
